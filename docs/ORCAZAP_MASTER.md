# OrçaZap — Master Build
## Produto
Micro SaaS independente de WhatsApp para prestadores criarem propostas profissionais rapidamente, com precificação orientativa.
## Princípios
Simplicidade; multi-tenant; Pricing Engine determinístico; IA assistiva; snapshot de proposta enviada; canais externos desacoplados.
## Roadmap
Fundação → autenticação/multi-tenant → clientes/serviços → precificação → orçamentos → compartilhamento/PDF → follow-up → IA → billing.
## Regra anti-remendo
Toda mudança deve ser validada em TypeScript/build, fluxo real, responsividade e isolamento por empresa antes da próxima fase.
